# 자료·양식 관리

## 자료 위치

| 자료 | 확인할 위치 | 작성 기준 |
| --- | --- | --- |
| 프로젝트 안내 | `README.md` | 프로젝트의 목적과 시작 방법을 정리합니다. |
| 작업 규칙 | `AGENTS.md` 또는 하네스 폴더 | 다음 작업에도 적용할 기준을 기록합니다. |
| 이슈·PR 양식 | `.github/` | 저장소에 있는 양식과 항목을 재사용합니다. |

## 자료 추가와 작업 메모

- 필요한 자료의 기존 위치와 이름 규칙을 먼저 찾습니다. 새로 만들면 관련 안내 문서에도 위치를 추가합니다.
- 진행 중인 메모와 임시 결과는 프로젝트의 임시 작업 위치에 두고, 재사용할 결론은 공식 문서에 정리합니다.
