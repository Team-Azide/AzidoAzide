# Unity 작업

## 작업 전 확인

- 대상 프로젝트, Unity 버전, 활성 Scene이나 Prefab을 확인합니다.
- Scene, Prefab, Component는 가능한 경우 Unity Editor에서 수정하고 관련 에셋의 `.meta` 파일을 함께 확인합니다.

## 저장과 검증

- 변경한 에셋, Scene, Prefab을 저장하고 의도한 대상에 반영됐는지 확인합니다.
- 관련 Edit Mode 또는 Play Mode 검증을 수행하고 Console 오류와 미검증 항목을 기록합니다. 화면 변경은 필요한 경우 대표 화면을 남깁니다.
