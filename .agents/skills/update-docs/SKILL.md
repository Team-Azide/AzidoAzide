# 문서 정리

## 문서 업데이트

1. 독자가 해야 할 일과 이 주제를 다루는 기존 문서를 찾습니다. 현재 코드와 설정에서 동작, 명령, 경로를 확인합니다.
2. 기존 문서의 용어와 구조를 따라 필요한 부분을 수정합니다. 반복 설명은 근거가 되는 문서에 두고 다른 위치에서는 링크로 연결합니다.
3. 영향을 받는 링크, 명령, 예제를 확인합니다. 실행 여부를 확인하지 못한 예제는 결과에서 구분합니다.

## 결과

바뀐 문서와 어떤 작업에 도움이 되는지 짧게 적습니다. 확인이 남은 내용이 있다면 함께 적습니다.
